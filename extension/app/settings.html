Where do the e-invoice details come from?

Pick Zoho Books e-invoicing only if this organization pushes invoices to the IRP through Books. Pick Custom fields only if the IRN was generated elsewhere (a GSP, the government portal, or an import) and the values were stored against the invoice as custom fields.

Custom field API names

Use the field's API name, not its label — find it under Settings › Preferences › Invoices › Field Customization. The signed QR field must hold the full JWS string returned by the IRP; it cannot be reconstructed from the IRN.

QR rendering

A signed QR is typically 800–1500 characters. Level L holds up to 2953 bytes; level M holds less, so raise it only if your payloads are short and your printer output is poor.
